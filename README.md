Сайт бьюти-салона "BeautySalon

Проект выполнен в рамках производственной практики (Модуль ПМ.05).

Описание проекта
Веб-приложение для салона красоты с возможностью онлайн-записи на услуги. 
Включает в себя клиентскую часть (личный кабинет) и панель администратора.

Функционал
- Регистрация и авторизация пользователей (с валидацией полей и проверкой уникальности email).
- Защита маршрутов: доступ к личному кабинету и админ-панели только для авторизованных пользователей.
- Личный кабинет клиента: создание новых заявок (выбор услуги, даты, типа оплаты) и просмотр истории своих записей.
- Панель администратора: просмотр всех заявок, фильтрация по статусу, изменение статуса заявки.
- UI/UX: адаптивная верстка под мобильные устройства, слайдер на главной странице, микроанимации, всплывающие Toast-уведомления.

Стек технологий
- Frontend: HTML5, CSS3, JavaScript (Vanilla JS).
- Хранение данных (Прототип): LocalStorage (JSON).
- База данных (Схема): Разработана структура реляционной БД (SQL Server), скрипт находится в файле `schema.sql`.

Структура проекта
- `index.html` — Главная страница (слайдер).
- `login.html` / `register.html` — Страницы входа и регистрации.
- `dashboard.html` — Личный кабинет клиента.
- `admin.html` — Панель администратора.
- `css/` — Стили проекта.
- `js/` — Скрипты логики (валидация, слайдер).
- `schema.sql` — SQL-скрипт для создания таблиц БД.
- `er_diagram.png` — ER-диаграмма базы данных.

 Как запустить
1. Скачайте проект.
2. Откройте файл `index.html` в любом браузере.
3. Для входа в панель администратора используйте логин `admin` и пароль `admin`.
