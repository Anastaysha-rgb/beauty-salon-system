# Информационная система "Салон красоты"

## Описание проекта
Минимально жизнеспособная информационная система (MVP) для автоматизации записи клиентов в салон красоты. Включает в себя личный кабинет клиента и панель администратора.

## Стек технологий (планируемый)
*   Frontend: HTML5, CSS3, Vanilla JS
*   Backend: Node.js (Express)
*   База данных: SQLite 

## Структура базы данных (Модуль 1)
*   `users` — пользователи (клиенты и админы).
*   `services` — список предоставляемых услуг.
*   `appointments` — записи клиентов (заявки).

## Сценарии использования
1.  **Регистрация/Авторизация:** Клиент создает аккаунт, валидация полей (ФИО, телефон, email, пароль).
2.  **Личный кабинет клиента:** Просмотр своих записей, создание новой записи (выбор услуги, даты).
3.  **Панель администратора:** Просмотр всех записей, фильтрация, изменение статуса (новая -> подтверждена -> выполнена/отменена).
